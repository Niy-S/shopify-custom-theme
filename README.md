# Shopify Custom Theme

A custom Shopify theme development project built using Shopify's Dawn theme as a foundation.

## Tech Stack
- Shopify Liquid
- HTML
- CSS
- JavaScript

## Project Goals
- Customize the Shopify storefront.
- Build responsive sections.
- Add a free-shipping progress bar to the cart.
- Improve website performance, accessibility, and SEO.

## Development Setup
1. Clone this repository.
2. Install Shopify CLI.
3. Run `shopify theme dev --store your-store.myshopify.com`.
